# Domain notes (read only your domain)

## Computer science

- Lead with a complexity table: `structure/algorithm | best | avg | worst | space`.
- Pseudocode: ≤6 lines each, in `\code{}` or `\texttt`. Keep only the invariant and the loop.
- State recurrences with the master-theorem case in one line.
- Add a "traps" list: off-by-one, stability, in-place, negative weights.
- Group by data structure or paradigm, not by lecture.
- Skip proofs; keep a one-line correctness idea.

## Mathematics

- Order: definition, theorem (with hypotheses), one-line key idea.
- Never drop quantifiers or conditions (`\forall`, `\exists`, "if and only if").
- List identities in one block. Add a counterexample for each common false converse.
- Use compact notation; define each symbol once.
- Standard integrals, series and limits go in a table.

## Statistics

- Open with a distribution table: `name | pmf/pdf | E | var | notes`.
- Boxes per method: estimator, SE, CI, test statistic, null distribution.
- State the assumption next to every formula (normal? iid? σ known?).
- Add a "which test or interval" decision table.
- Mark parameter (θ), estimator (hat, random), estimate (hat, number).
- Watch for: `n` vs `n-1`, SE vs SD, one- vs two-tailed, `z` vs `t`.
